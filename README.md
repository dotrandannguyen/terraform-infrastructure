# AWS Fullstack Project

Dự án triển khai Fullstack App (Node.js + React) lên AWS bằng Terraform, ECS Fargate, Docker và GitHub Actions.

## Cấu trúc thư mục

- `backend/`: Chứa source code Node.js + Express
- `frontend/`: Chứa source code React + Vite
- `infrastructure/`: Chứa toàn bộ code Terraform quản lý hạ tầng AWS
- `.github/workflows/`: Chứa pipeline CI/CD bằng GitHub Actions
